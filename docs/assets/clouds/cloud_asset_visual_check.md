# Cloud Asset Visual Check

Use this checklist for both:

- `cloud_alpha_2048x1024.png`
- `cloud_alpha_4096x2048.png`

## Checklist

1. Global equirectangular projection.
2. 2:1 aspect ratio.
3. Cloud areas are white or light gray.
4. No-cloud areas are black or near black.
5. No terrain color contamination.
6. No borders.
7. No watermark.
8. No text.
9. Cloud density is not too high.
10. Cloud edges are soft.
11. Low-opacity overlay does not look dirty.
12. Night rendering should not obviously block city lights.
13. Suitable for E1 cloudMesh minimal construction.
