# Horizon Mode 美学基调 v1.0

> 2026-07-19 确立，随 Horizon Mode（issue #36，milestone "Horizon Mode — Independent Scene Build"）建设过程持续参考。后续 Phase 2（天空穹顶）、Phase 3/5（海面技术与打磨）、Phase 8（山地场景）的所有视觉判断都应对照本文。

## 核心判断：从上帝视角，切换到真实的看见

Orbit 模式看到的是抽象的地球——一颗蓝色弹珠，云带、海陆轮廓、灯光斑点，一切都被距离拉平成符号。地平线模式要做的是反过来：站在地上，看见具体的东西——山有多高、丘陵有多不平整、水有多少种不一样的质地。这是"看见"，不是"俯瞰"。

## 海水不是一种颜色，是一整套地理事实

大溪地那种清澈见底，能看到浅滩的沙纹和珊瑚礁的轮廓；上海入海口那种浑浊，泥沙让水变成不透明的黄褐色；深海区那种深蓝到近黑，光线到某个深度就消失了。这些不是"风格选项"，是不同地点的真实水质——地平线模式要能表现这种差异，而不是所有海都用同一套"深色反光水面"模板打发。

**技术含义**：Phase 3/5 的海面渲染需要参数化水质系统，至少支持三个维度：
- 透明度（清澈见底 vs 完全不透明）
- 浑浊度（泥沙悬浮感，影响散射和颜色）
- 基底颜色（热带turquoise / 河口黄褐 / 深海近黑）

建议先做三个典型 water profile 作为起点：热带浅滩、河口浑浊、深海。

## 云是点缀，不是主角，但不能没有

喜马拉雅、阿尔卑斯那种缠在山腰的云、灌满山谷的雾，是那类风景真正的一部分，不出现会显得假。海平线场景云可以更克制、更稀薄；但山地场景（Phase 8）如果完全没有云雾缠绕，就丢掉了"巍峨"这个感觉最重要的一层。

## 克制指的是不要戏剧化，不是不要真实感

不追求度假海报的饱和色、不追求 HDR 摄影那种到处都锐利清晰的通透感、不用音乐节拍去打点闪烁反射——这些是要避开的"讨好"。但山该有山的体量感，水该有水的质地差异，这些不能因为"克制"就一起磨平。

## 明确要避开的三种感觉

- **摄影 App 的精修感**——太干净、太讨好眼球
- **飞行模拟器的机械感**——太规整、太多 HUD 式信息
- **冥想 App 的甜腻感**——马卡龙渐变、过饱和暖色

## 参照系

坂本龍一那种质感——留白、有呼吸感，但留白的是情绪的张扬，不是内容本身的丰富度。RodiO 要的是这个调子，不是 Windows 桌面壁纸的调子。

## 执行原则

用户明确要求：精细化地做，可以分批次分阶段推进，但最终必须全部完成——这是排期问题，不是范围问题。不接受为了"先跑起来"而永久性地简化掉水质差异、云雾层次或地形体量感。
