# RodiO 地球日间贴图配色执行方案

## 主题：Noon Air Earth / 正午空气蓝地球

本方案用于调整 RodiO 日间地球贴图，不修改 UI、不修改夜景、不修改云层。目标是在保持真实地理识别度的基础上，形成清透、明亮、克制、具有高空正午低轨道视角的审美化地球质感。

---

## 0. 总体原则

```text
深海要清澈，不要黑。
浅海要发光，但不要荧光。
陆地要低饱和，不要地图绿。
沙漠要暖，但不要过曝。
冰原要蓝白有纹理，不要死白。
群岛要有浅海光晕，不要只剩小点。
大气要轻薄，不要灰雾糊图。
```

整体观感应接近：

```text
冷调正午蓝 + 清透深海 + 克制浅海青蓝 + 低饱和陆地 + 暖沙色沙漠 + 蓝白冰原
```

禁止方向：

```text
禁止 NASA 黑蓝高对比风格。
禁止 Google Earth 原始卫星硬对比风格。
禁止游戏地图式高饱和绿蓝。
禁止复古地图黄褐色。
禁止全图灰化、脏化、暗化。
禁止牺牲真实地理识别度来追求统一色调。
```

---

## 1. 全局色彩控制

### 1.1 全局基础参数

建议作为最终调色前的基准控制，不建议一开始全局暴力套滤镜。

```text
全图亮度：+3% 至 +6%
全图对比度：-3% 至 -6%
全图饱和度：-4% 至 -8%
蓝色通道亮度：+4% 至 +8%
绿色饱和度：-8% 至 -15%
黄色饱和度：-5% 至 -12%
```

执行目的：

```text
1. 降低传统卫星图的硬对比。
2. 避免绿色、沙漠黄色过艳。
3. 保持海洋清透感。
4. 让地球更接近低轨道正午视角，而不是平面地图。
```

### 1.2 全局空气蓝叠层

最终可增加极轻的冷蓝空气感，但必须非常克制。

```text
叠加颜色：#8FC4E6
混合模式：soft light 或 screen
透明度：4% 至 8%
最大透明度：不得超过 10%
```

禁止：

```text
不要让陆地发灰。
不要让沙漠变脏。
不要让极地失去纹理。
不要让整张图像蒙了一层厚蓝雾。
```

## 2. 海洋系统配色

海洋是 RodiO 地球的主视觉基础。必须形成“深海—中海—大陆架—近岸浅海—礁盘”的连续层次。

### 2.1 深海

适用区域：

```text
太平洋深海、大西洋深海、印度洋深海、南大洋深海、远离大陆架的海盆区域。
```

目标效果：

```text
清澈深蓝，有厚度，但不接近黑色。
```

推荐色阶：

| 类型 | 色值 | 用途 |
|---|---:|---|
| 最深海沟 | `#03243F` | 海沟、极深海暗部 |
| 深海主体 | `#05395F` | 大面积深海主色 |
| 中深海 | `#07527A` | 深海向中海过渡 |
| 受光远海 | `#126B92` | 海面受光区、高空远景 |
| 远景雾化海面 | `#3E8DB0` | 接近地平线的大气淡化区域 |

执行要求：

```text
1. 最深海区域允许接近 #03243F，但不能低于该亮度。
2. 大面积深海主体应控制在 #05395F 到 #07527A。
3. 海面高光和远景区域可轻微提升到 #126B92。
4. 不能出现纯黑、墨蓝、灰蓝。
5. 深海纹理可以保留，但不要让海底沟壑变成黑色裂缝。
```

### 2.2 中浅海 / 大陆架

适用区域：

```text
黄海、东海、南海北部、波斯湾、红海、地中海近岸、加勒比海外围、澳大利亚大陆架、北海、波罗的海。
```

目标效果：

```text
比深海更亮，带青蓝过渡，体现大陆架浅水区。
```

推荐色阶：

| 类型 | 色值 | 用途 |
|---|---:|---|
| 大陆架深蓝 | `#0A5F84` | 深海向大陆架过渡 |
| 大陆架主色 | `#197FA0` | 大陆架主体 |
| 浅水过渡 | `#2FAAC0` | 近岸浅海 |
| 明亮浅水 | `#53C8D1` | 少量浅水高光 |

执行要求：

```text
1. 大陆架边缘必须有渐变，不允许深海直接切到浅海。
2. 近岸水域应从 #197FA0 过渡到 #2FAAC0。
3. 浅水高光只允许局部出现，不要铺满整片海域。
4. 黄海、渤海可以稍微灰一点，但不能浑浊发黄。
5. 地中海、爱琴海、加勒比可以更清透。
```

## 3. 群岛与礁盘配色

群岛必须单独处理。群岛不能只是陆地小点，而应当形成：

```text
岛屿核心 + 沙滩边缘 + 浅海环 + 礁盘高光 + 外海过渡
```

### 3.1 热带群岛通用规范

适用区域：

```text
马尔代夫、塞舌尔、巴哈马、加勒比小安的列斯群岛、斐济、汤加、萨摩亚、法属波利尼西亚、库克群岛、密克罗尼西亚、帕劳、所罗门、瓦努阿图、印尼东部群岛、菲律宾中南部群岛。
```

目标效果：

```text
小岛周围有清晰但克制的青蓝浅海光晕，能在地球视角中被识别。
```

推荐结构：

| 层级 | 色值 | 用途 |
|---|---:|---|
| 岛屿陆地核心 | `#4D7A56` 至 `#6E8F63` | 小岛植被 |
| 火山岛暗绿 | `#355F43` | 夏威夷、塔希提等高岛 |
| 沙滩边缘 | `#D8C99D` | 极窄岸线 |
| 极浅水 | `#A9EFEA` | 最浅水高光 |
| 礁盘青蓝 | `#5FD3D8` | 环礁、珊瑚礁 |
| 浅海主色 | `#2FAAC0` | 岛屿周边浅海 |
| 外海过渡 | `#197FA0` | 浅海向深海过渡 |
| 深海外缘 | `#07527A` | 外围深海 |

执行规则：

```text
1. 每个热带小岛周边应保留 1 至 4 像素的浅海青蓝环，视贴图分辨率放大或缩小。
2. 浅海环不能是纯白，不能是荧光青。
3. 礁盘高光 #A9EFEA 只能用于最浅水区，面积不超过该岛周边浅海区域的 15%。
4. 岛屿陆地不能过黑，应保持低饱和绿色或灰绿色。
5. 小岛边缘不允许被深海蓝直接吞没。
6. 群岛密集区域应形成细碎的青蓝层次，而不是一整片亮蓝色块。
```

### 3.2 巴哈马 / 加勒比浅滩

巴哈马是浅海表现的标杆区域，但必须避免廉价荧光感。

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 浅滩主体 | `#6ED9DE` |
| 极浅沙洲水色 | `#B7EFE8` |
| 浅海过渡 | `#36B8C8` |
| 外缘海 | `#13789A` |
| 深海 | `#06395F` |

执行要求：

```text
1. 巴哈马浅滩可以比其他区域更亮。
2. 最高亮度不得超过 #B7EFE8。
3. 浅滩边缘必须柔化，不能有硬边色块。
4. 深浅海交界要体现海底地形坡度。
5. 不允许把加勒比全部调成同一种浅蓝。
```

### 3.3 马尔代夫 / 环礁

目标效果：

```text
环礁应当像散落在深海中的细小青蓝光点，但不能像发光灯泡。
```

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 环礁外圈 | `#5FD3D8` |
| 环礁内湖 | `#8AE6E4` |
| 极浅高光 | `#B5F0EC` |
| 外海 | `#05395F` |

执行要求：

```text
1. 环礁只允许小面积提亮。
2. 环礁周边外海必须保持深蓝，形成对比。
3. 不允许把整个马尔代夫区域涂成一片浅蓝。
4. 高光点必须细碎、自然、沿真实环礁分布。
5. 环礁高光应优先保留环状结构，不要变成圆形亮斑。
```

### 3.4 太平洋高岛群

适用区域：

```text
夏威夷、斐济、萨摩亚、汤加、塔希提、马克萨斯群岛、所罗门、瓦努阿图。
```

推荐配色：

| 类型 | 色值 |
|---|---:|
| 火山岛陆地 | `#355F43` |
| 山地阴影 | `#2F4B3F` |
| 低地绿 | `#5F8558` |
| 近岸浅海 | `#39B8C8` |
| 外海 | `#05436B` |

执行要求：

```text
1. 火山岛陆地应偏深绿，不要鲜绿。
2. 岛屿边缘保留窄浅海圈。
3. 夏威夷周边浅海不应过亮，保持深海包围感。
4. 法属波利尼西亚和斐济可以有更明显青蓝礁盘。
5. 高岛应保留山体阴影，不能处理成扁平绿点。
```

### 3.5 高纬群岛

适用区域：

```text
加拿大北极群岛、斯瓦尔巴群岛、法兰士约瑟夫地群岛、格陵兰周边岛屿、南乔治亚、南设得兰群岛。
```

推荐配色：

| 类型 | 色值 |
|---|---:|
| 冰雪岛屿 | `#DDECF2` |
| 冰川阴影 | `#9CB8C8` |
| 裸岩边缘 | `#6E6A5D` |
| 冷海浅水 | `#63AFC8` |
| 极地海 | `#0A4D72` |

执行要求：

```text
1. 高纬群岛不能使用热带青蓝。
2. 浅海应偏冷蓝、灰蓝，而不是荧光青。
3. 冰雪岛屿要有蓝灰阴影，避免一片白。
4. 裸露岩石边缘可以保留灰褐色，增强真实感。
5. 高纬岛屿边缘要有冷海过渡，不要白色直接贴深海。
```

## 4. 冰原与极地配色

冰原必须单独控制。南极、格陵兰、北极群岛的处理方式不同。

### 4.1 南极冰盖

目标效果：

```text
巨大、干净、蓝白、有纹理，不刺眼，不死白。
```

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 冰盖暗部 | `#9CB8C8` |
| 冰盖中间调 | `#C9DEE8` |
| 冰雪主色 | `#DDECF2` |
| 冰雪亮部 | `#F2F8FA` |
| 冰裂缝阴影 | `#7FA6BA` |
| 近岸冰海 | `#63AFC8` |

执行要求：

```text
1. 南极主体不能使用纯白 #FFFFFF。
2. 大面积主色应控制在 #DDECF2 左右。
3. 高光 #F2F8FA 只能用于受光区域和冰脊顶部。
4. 冰盖纹理必须保留，不能被亮度提升抹平。
5. 冰裂缝、山脊、冰流线应使用 #9CB8C8 到 #7FA6BA 的蓝灰阴影。
6. 南极边缘与海洋交界处必须有冷蓝过渡，不允许白色直接贴深海。
```

### 4.2 格陵兰冰盖

格陵兰要比南极更有地形感。

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 冰盖中心 | `#E2EFF3` |
| 冰盖阴影 | `#A8C4D2` |
| 冰川流线 | `#8FAFC0` |
| 山地裸岩 | `#5E5C50` |
| 峡湾冷海 | `#4FA6C2` |
| 近岸浅冰海 | `#86D0D8` |

执行要求：

```text
1. 格陵兰中央冰盖可以较亮，但不能死白。
2. 东西海岸山地必须保留灰褐裸岩和阴影。
3. 峡湾区域应有冷青蓝水色，不能全部深蓝。
4. 冰盖边缘要从蓝白过渡到裸岩，再过渡到海水。
5. 不允许把格陵兰处理成一整块白色贴片。
```

### 4.3 北极海冰 / 高纬海域

适用区域：

```text
北冰洋、加拿大北极群岛周边、格陵兰海、巴伦支海、南大洋浮冰区。
```

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 极地海主色 | `#0A4D72` |
| 冰海过渡 | `#2F83A1` |
| 薄冰蓝 | `#A8DCE4` |
| 海冰白 | `#E6F2F5` |
| 冰缝阴影 | `#6A9DB4` |

执行要求：

```text
1. 海冰要比陆地冰盖更薄、更碎。
2. 浮冰不能大面积纯白。
3. 冰缝应保留蓝灰线条。
4. 海冰与海水之间要有透明感，不要像白色油漆。
```

## 5. 陆地植被配色

### 5.1 温带森林与平原

适用区域：

```text
欧洲中部、中国东部、日本、朝鲜半岛、美国东部、加拿大南部、俄罗斯西部。
```

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 深森林 | `#244A3A` |
| 普通森林 | `#426D4D` |
| 平原绿 | `#6E8F63` |
| 浅绿农田 | `#8FA77A` |
| 城市灰绿混合 | `#7C8376` |

执行要求：

```text
1. 陆地绿色整体降低饱和度。
2. 不允许出现鲜绿色、荧光绿色。
3. 农田和平原可以稍亮，但必须偏灰绿。
4. 城市群区域不要做成明显灰白块，应与周边地表自然融合。
5. 日本、欧洲、中国东部可以略微更绿，但不能超过 #8FA77A 的明亮程度。
```

### 5.2 热带雨林

适用区域：

```text
亚马逊、刚果盆地、东南亚、巴布亚新几内亚、婆罗洲。
```

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 雨林暗部 | `#1F3F32` |
| 雨林主色 | `#2F5A3E` |
| 湿润绿 | `#4F7651` |
| 雾化绿 | `#6F8C68` |

执行要求：

```text
1. 雨林应比温带森林更深、更密。
2. 不要鲜绿，要偏深橄榄绿。
3. 亚马逊不能做成一整片平绿，要保留河流纹理。
4. 东南亚岛屿雨林可稍亮，但必须有地形阴影。
```

### 5.3 草原 / 稀树草原

适用区域：

```text
非洲东部、南美潘帕斯、蒙古草原、中亚部分区域、澳洲北部。
```

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 干草黄绿 | `#9A966B` |
| 草原主色 | `#8A8F61` |
| 稀树草原 | `#A3916E` |
| 湿润草地 | `#7D8F61` |

执行要求：

```text
1. 草原应介于绿色和沙色之间。
2. 不要处理成沙漠黄。
3. 非洲东部可以偏暖，中亚草原可以偏灰。
```

## 6. 沙漠与干旱区配色

### 6.1 撒哈拉 / 阿拉伯半岛

目标效果：

```text
暖沙色，有细节，不刺眼。
```

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 沙漠阴影 | `#8D6D4F` |
| 沙漠主色 | `#C49B6F` |
| 受光沙地 | `#D8BC91` |
| 沙丘高光 | `#E6D0A8` |
| 岩石暗部 | `#6F5A45` |

执行要求：

```text
1. 撒哈拉和阿拉伯半岛不能大面积超过 #D8BC91。
2. #E6D0A8 只能用于沙丘高光和局部明亮区域。
3. 山地、干河谷、岩石区必须保留 #8D6D4F 至 #6F5A45 的阴影。
4. 埃及、阿拉伯半岛当前最容易过曝，必须压低高光。
5. 沙漠不能偏黄绿，也不能偏白。
```

### 6.2 中亚 / 伊朗高原 / 青藏高原边缘

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 高原灰褐 | `#A3916E` |
| 干旱土色 | `#9B8062` |
| 山地阴影 | `#5F5A4E` |
| 盐湖浅色 | `#D7D2BF` |
| 雪线 | `#D8E0DE` |

执行要求：

```text
1. 高原不能像沙漠一样金黄。
2. 应偏灰褐、土色、岩石色。
3. 青藏高原要保留寒冷感，不能暖化过度。
4. 盐湖和干湖盆可以浅，但不能纯白。
```

### 6.3 澳大利亚内陆

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 红褐土 | `#A96F4F` |
| 干旱橙褐 | `#B9825A` |
| 浅土色 | `#C9A276` |
| 灌木灰绿 | `#8A8A65` |

执行要求：

```text
1. 澳洲内陆可以比撒哈拉更红。
2. 不能整体变成橙色块。
3. 东部沿海应保留绿色，内陆逐渐转为红褐。
```

## 7. 山地与高原配色

### 7.1 喜马拉雅与青藏高原

推荐色阶：

| 类型 | 色值 |
|---|---:|
| 高原冷土色 | `#A3916E` |
| 山体灰褐 | `#7A6E5A` |
| 阴影灰 | `#4C4F45` |

## 9. 区域优先级与执行流程

### 9.1 区域优先级

```text
第一优先级：海洋整体色阶
第二优先级：浅海、群岛、礁盘
第三优先级：冰原与极地
第四优先级：沙漠与高原
第五优先级：森林与平原
第六优先级：全局空气蓝和最终统一
```

### 9.2 正确执行流程

```text
1. 先锁定深海色阶。
2. 再单独增强浅海与群岛。
3. 再修正冰原，避免过曝。
4. 再压低沙漠高光。
5. 再降低陆地绿色饱和度。
6. 最后加极轻空气蓝统一画面。
```

不建议：

```text
不要一开始就全局调色。
不要一次性用单一 LUT 覆盖所有区域。
不要通过整体增加饱和度来增强浅海。
不要通过整体提高亮度来处理冰原。
```
