# 05 Earth Camera Motion Music Implementation v3.1

## 0. 定位

本文件处理地球不再像固定地球仪的问题。

目标不是炫技，而是建立：

```text
Earth Camera Presets / 地球观测视角系统
```

地球角度、镜头距离、画面位置、地平线弧度、倾斜角、转场速度和音乐状态共同构成“镜头语言”。

---

## 1. 视角预设

| 视角 | 特征 | 适用场景 |
|---|---|---|
| Globe View | 完整地球仪视角 | 默认、定位、正午、普通播放 |
| Horizon View | 地球只露出局部弧线，低轨道感 | 孤独、夜晚、日出、落日、氛围音乐 |
| Low Orbit View | 更贴近地表，城市/海岸占比更高 | 城市歌单、旅行、夜景灯光 |
| Deep Space View | 地球较小，深空留白强 | ambient、后摇、深夜、暂停 |
| Hemisphere View | 北/南半球倾斜主题视角 | 《孤单北半球》、半球主题歌曲 |
| City Focus View | 缓慢转向城市或区域 | 地点歌单、城市歌曲、用户定位 |
| Ocean View | 面向太平洋/印度洋等大面积海域 | 海洋、旅行、空灵歌曲 |

---

## 2. 近期只做什么

允许：

- 设计参数结构；
- 只读审计当前相机/地球旋转逻辑；
- 增加调试用 preset 切换；
- 做缓慢转场验证；
- 不与地图母版、云层、大气辉光同轮提交。

禁止：

- 每首歌自动语义识别；
- 快速镜头切换；
- 跟鼓点抖动；
- AI 自动生成镜头；
- 大幅破坏现有定位逻辑；
- 强行做复杂音乐推荐联动。

---

## 3. 音乐联动原则

核心原则：

```text
音乐影响地球的呼吸，不是操控地球跳舞。
```

### Level 1：播放状态联动

- 播放：地球缓慢自转；
- 暂停：逐渐减速；
- 切歌：缓慢重新构图；
- 歌曲结束前：极缓减速；
- 下一首开始：新的轻微运动。

### Level 2：音乐情绪联动

- 慢歌 / ambient：近乎静止；
- 情绪流动歌：缓慢漂移；
- 明亮歌曲：更通透、更开阔；
- 夜晚城市歌：Low Orbit / City Focus；
- 孤独主题：Horizon / Deep Space / Hemisphere。

### Level 3：地点联动

远期。根据歌名、歌单、艺人、用户地点或手动标签转向城市/海域。

---

## 4. 《孤单北半球》示例

不应简单显示完整地球。更适合：

```text
North Hemisphere / Horizon View
```

视觉特征：

- 北半球倾斜；
- 地球弧线更明显；
- 夜色或冷蓝色调；
- 城市灯光克制；
- 低轨道孤独感；
- 转场 8–20 秒，不能突兀。

---

## 5. 验收标准

1. 用户第一眼仍看到地球，而不是动画效果；
2. 转场慢、轻、自然；
3. 不像游戏镜头；
4. 不像音游可视化；
5. 不破坏定位；
6. 可回到默认 Globe View；
7. 每个 preset 可通过 debug state 查看当前参数。
