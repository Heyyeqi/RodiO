## 0. 本文件的作用

本文件是 E1 Day Earth Master 的**量化参考基线**，不是施工指令。

它回答：
- RodiO 当前白天地图在哪些区域偏离了真实参考？偏离多少？
- 偏离的方向是过曝、过饱和、过平，还是卡通化？
- 沙漠和极地过曝的根因是贴图本身还是光照/大气系统？
- 什么是足够好的白天母版，而不是无限优化的借口？

本文件不替代 Phase 2（D5b 待验收）、D5z 专项、云层专项、极地光照专项。
D5z 是本文件约束下的子任务，不可超出本文件定义的边界。

## 1. E1 总目标

### 1.1 核心目标

形成**长期可复用的白天地球母版**，不再每轮无限生成候选。

白天母版必须同时满足：
1. 海洋有层次：浅海、陆架、深海有可见差异；
2. 太平洋小岛周边有领土感；
3. 沙漠不过曝（在 noon 模式下不泛白）；
4. 极地冰川保留纹理（有灰度厚度，不均质全白）；
5. 重点海域有可辨识特色；
6. 陆地地貌有层次（山地、雨林、沙漠、平原视觉可区分）；
7. 整体审美不低于参考（真实、有高级感，不像教材地图）。

### 1.2 关于极地过曝的特别说明

**E1 不直接修复极地过曝。**

但 E1-R2 必须完成极地与沙漠的**过曝归因审计**，明确问题属于哪一层：

```
归因路径：

Step 1：测量 d5b_design_v3_2_1 贴图像素本身的 L*（从 JPG 文件直接测量，
        不在浏览器中，不受光照影响）

  → 贴图 L* 在参考范围内（正常）：
      Step 2：在浏览器 noon 模式下截图，测量屏幕亮度
        → 屏幕亮度远高于贴图值
          → 根因：光照 / atmosphere / specular 参数 → 进入 Phase 7
        → 屏幕亮度接近贴图值（贴图本身偏亮）
          → 根因：贴图亮度基线偏高 → 进入 E1-R3 候选生成

  → 贴图 L* 本身异常（std_L < 4 或 L* 整体过高）：
      → 根因：贴图纹理丢失或亮度误调 → 进入 E1-R3 候选生成
```

**分类结论：**

| 根因 | 处理阶段 | 本轮动作 |
|---|---|---|
| noon sun / ambient / atmosphere 过强 | Phase 7 | E1-R2 记录归因，不在 E1-R3 动贴图 |
| specular 对冰雪产生不自然高光 | Phase 7 | 同上 |
| 贴图本身 std_L < 4（纹理丢失） | E1-R3 候选生成 | 贴图层修复，不动光照 |
| 贴图 L* 均值过高（非光照原因） | E1-R3 候选生成 | 同上 |

> E1-R2 必须输出明确归因结论，不允许停留在"可能有关"的模糊判断。若为贴图层、光照层两者叠加，必须分别量化贡献，并明确哪一层作为优先修复对象。

### 1.3 非目标（本阶段不处理）

| 非目标 | 归属阶段 |
|---|---|
| 极地过曝修复（归因后确认为光照问题） | Phase 7 |
| 城市灯光 / 夜晚地图 | E2 Night Earth Master |
| 云层 | E4 Cloud Layer |
| 大气辉光 | E5 Atmospheric Limb Glow |
| 11 时段色彩联调 | E6 Time Modes Integration |
| 大堡礁/马尔代夫礁盘精细化 | Phase 8（暂缓） |
| 实时天气 / 七曜 / 节气 | 远期冻结 |

### 1.4 "好的白天母版"定义

通过以下所有检查才能宣告 E1 完成：

```
[ ] 各类区域 current_vs_reference_deltaE < E1-R1 校准后阈值
[ ] 六大问题域无 High Risk 标记
[ ] 三源一致的区域不出现反向偏差
[ ] 深海无 ETOPO1 洋底纹理泄漏（std_L ≤ 3）
[ ] 陆地/冰雪 mask 有效（max_abs_diff ≤ 4）
[ ] E1-R2 归因审计完成，极地/沙漠过曝根因已明确
[ ] 全局 on-globe 视觉验收通过（RW 人工判断）
[ ] 后续阶段（云层、夜晚）可在本母版上叠加，不需推倒重做
```

| 字段 | 内容 |

| 数据集 | 用途 | 获取路径 | 优先级 |
|---|---|---|---|
| BMNG 1 月版 | 南北极冰盖季节差、南半球植被 | visibleearth.nasa.gov BMNG monthlies | 高 |
| BMNG 4 月版 | 春季过渡季节 | 同上 | 中 |

| NEO Sea Surface Temperature | 冷/暖洋流对水色影响辅助 | neo.gsfc.nasa.gov → Ocean → SST | 中 |
| NASA Worldview MODIS TrueColor | 特定区域高分辨率真彩验证（最高 250m/px） | worldview.earthdata.nasa.gov | 按需 |

**季节差异注意事项：**

| 区域 | 8 月 vs 1 月 | 对 E1 影响 |
|---|---|---|
| 北极海冰 | 8 月退缩，1 月扩大 | 8 月版北极海冰最少，热带海洋最稳定 |
| 南极 | 8 月冬季（冰最多），1 月夏季（冰最少） | 极地过曝主因是光照，不是季节 |
| 亚马逊 | 8 月植被最密 | 雨林绿色最深，是 E1 绿色上限基准 |
| 撒哈拉 | 全年稳定 | 任意月份均可作为沙漠参考 |
| 北海/波罗的海 | 春季叶绿素爆发 | C5/C6 样本避开 3–5 月 |

**NASA 作为全局基准的限制：**
- 8K 贴图每像素覆盖约 5km，无法分辨长滩岛礁盘、马尔代夫单个环礁；
- NASA 用于全球海陆整体关系、沙漠/雨林/冰原颜色基调；
- 局部细节必须依赖 Sentinel-2 校验。

### 2B. Copernicus / Sentinel-2 / ESA — 遥感真实性校验

| 字段 | 内容 |
|---|---|
| 访问入口 | browser.dataspace.copernicus.eu |
| 数据类型 | Sentinel-2 L2A，True Color (TCI / B04+B03+B02) |
| 分辨率 | 10m/px |
| 注册 | 免费，Copernicus 账户 |
| 云量限制 | 热带 < 5%；温带 < 10%；高纬 < 15% |

**采样操作规程（每点）：**

```
1. 导航至目标坐标（± 0.5° 范围）
2. 选图层：Sentinel-2 L2A → True Color (TCI)
3. 时间范围：对应推荐月份，近 2 年内，多选几景取最清晰
4. 云量筛选 < 10%（筛选器设置）
5. 截图并标注：数据集、过境日期(YYYY-MM-DD)、云量%、坐标范围
6. 文件命名：s2_[地点]_[日期]_[云量]pct.jpg
   示例：s2_boracay_20250114_2pct.jpg
7. 存入：pwa/assets/source/bathy/reference/e1_reference/sentinel2/
```

**ESA WorldCover 补充（mask 验证）：**

```
网址：worldcover2021.esa.int/viewer
用途：验证 land mask 完整性，识别潮间带/红树林/湿地
仅用作 mask 验证，不用作颜色提取
```

## 4. 指标体系

### 4.0 暂定阈值全局说明

> **重要：所有标注为"暂定"的阈值不得作为候选通过或不通过的唯一依据。**
>
> 当前暂定阈值基于 D5b 历史经验和先验知识设定，是方向性参考，不是测量结论。

| 指标 | 含义 | 测量方式 |

## 5. 六大问题域判定规则

### 5A. 海洋层次不足

**触发条件（满足任一）：**
```
- 浅海与深海区域 deltaL < 8
- 热带浅海（A 类）mean_HSV.S < 30%
- 浅海与深海边界处 edge_density < 0.015
- A 类采样点 current_vs_ref_deltaE > E1-R1 校准后阈值
```

**诊断路径：**
```
1. 确认 D5b weight 参数是否已生效（区域是否有颜色变化）
2. 确认 blur 是否过大（层次被平滑）
3. 层次消失 → 候选方向：D5c（回升 weight）
4. 层次存在但太强 → 降 weight + 增 blur
```

**严重级别：** 3 个以上 A 类采样点触发 → **High Risk**

---

### 5B. 太平洋岛屿领土感不足

**触发条件（满足任一）：**
```
- A7（帕劳）、A6（塞舌尔）区域视觉无可辨识岛礁轮廓
- island halo 区域与周边深水 deltaL < 4
- 直径 < 50px 的岛礁周边无色差圈
```

**诊断路径：**
```
1. 检查 ISLAND_HALOS 参数是否生效
2. 确认 ETOPO1 分辨率是否足以在 8K 图中表达岛礁
3. 若不足 → 考虑 coastline distance proxy（轻量方案）
4. 若 halo 存在但不可见 → 扩大 radius 或提升 blend_strength
```

**注意：** 8K/5km 精度下，仅约 >25km 的岛礁可有明确浅海表达。

---

### 5C. 沙漠过曝

**触发条件（满足任一）：**
```
- E 类采样点在 browser noon 截图后，L* > 92（目视泛白）
- E 类贴图本身 deltaL > +8（相对 NASA 参考）
- E 类 p95_L > 90（暂定；E1-R1 后重新确认）
```

**归因流程（必须完成，E1-R2 任务）：**
```
Step 1：从 d5b_design_v3_2_1.jpg 直接测量 E 类采样点贴图 L*
  → 贴图 L* 在参考范围（70–84）：
      Step 2：browser noon 截图测量
        → 截图 L* > 88 → 光照/atmosphere 问题 → Phase 7
        → 截图 L* ≤ 88 → 贴图层问题 → E1-R3
  → 贴图 L* 本身 > 86 → 贴图层问题 → E1-R3
```

**不得在 E1-R2 归因前对沙漠做任何贴图修改。**

---

### 5D. 极地过曝 / 冰川纹理丢失

**触发条件（分别判断）：**
```
过曝（E1-R2 归因后判断）：
- F 类在 browser noon 截图中目视均质全白
- E1-R2 归因流程确认根因

纹理丢失（可直接从贴图测量）：
- F 类贴图像素 std_L < 4
- D5b vs D3 的 F 类区域 max_abs_diff > 8（贴图误伤）
```

**归因流程（E1-R2 任务，与 5C 共用）：**
```
Step 1：从 d5b_design_v3_2_1.jpg 测量 F 类贴图 L*（不在浏览器）
  → 贴图 L* 在 87–96：贴图本身正常
      → E1-R2 浏览器截图：若截图远亮于贴图 → 光照/atmosphere/specular → Phase 7
  → 贴图 std_L < 4：纹理丢失 → E1-R3 贴图候选
  → 贴图 L* 整体 > 96：贴图亮度基线异常 → E1-R3
```

**已知状态（D5b v3.2.1）：**
- Antarctica max_abs_diff = 25 → 贴图层保护有效，非误伤
- 预期归因：极地过曝为光照/atmosphere → Phase 7
- E1-R2 必须正式验证并记录此结论

---

### 5E. 陆地地貌糊化或卡通化

**触发条件（任一）：**
```
糊化：
- G 类 std_L < 6
- G 类 edge_density < 0.02
- H 类与 E 类之间 Lab 色相差 < 30°

卡通化：
- 任何区域颜色比对接近 Natural Earth 制图配色
- H 类 mean_HSV.S > 68%
- 全局饱和度相比 NASA BMNG 偏高 > 15%
```

---

### 5F. 全局不真实 / 过度调色

**触发条件（任一）：**
```
- 全局（50 点均值）current_vs_ref_deltaE > 14（暂定）
- 50 点中超过 15 点的 deltaS > +12%
- 与 Natural Earth 配色方向一致
- RW 主观判断"像壁纸/滤镜/插画"
```

## 7. 三方确认规则（扩展到所有地貌类型）

### E1-R4A：Regional Visual Preview（区域效果图预览）

**目标：**
在任何 E1-R3 / D5z / Day Master 候选生成后，必须先生成区域视觉预览图，让 RW 判断配色、真实感、局部改动和误伤情况。**没有 Regional Visual Preview，不得进入 E1-R5，也不得进入 production decision。**

**允许：**
- 读取 bmng_d2、d5b_design_v3_2_1、新候选贴图；
- 生成区域裁图；
- 生成 before / after / diff 对比图；
- 生成 saturation diff、Lab L* diff、RGB diff summary；
- 输出预览目录和 Markdown 报告。

**禁止：**
- 在 E1-R4A 中继续修改贴图；
- 在 E1-R4A 中调整生成参数；
- 在 E1-R4A 中修改 earth3d.js；
- 在 E1-R4A 中直接 production 化。

**必须输出：**
1. 平面区域对比图（bmng_d2 / d5b_design_v3_2_1 / new_candidate，三列并排，同裁剪范围）；
2. 差异图（abs diff / saturation diff / Lab L* diff / RGB channel diff summary）；
3. 局部放大图（必看区域见下）；
4. 固定视角上球截图（noon 模式，固定相机，写明 URL 参数 + 定位坐标 + 截图路径）；
5. 区域 pass / fail 判断清单；
6. RW 人工确认项列表。

**必看区域分三类：**

A. 必须改善区：
长滩岛 / Boracay、马尔代夫、巴哈马、大堡礁、帕劳、夏威夷、红海。

B. 必须保护区（不得热带化/不得新增伪影）：
波斯湾、黄海、长江口、孟加拉湾、亚马逊河口、太平洋深海、印度洋深海。

C. 不得误伤区：
南极、格陵兰、撒哈拉、阿拉伯半岛、澳洲内陆、亚马逊雨林、青藏高原。

**通过标准：**
- 目标区域确有改善；
- 非目标区域无可见变化；
- 深海不发灰；
- 浑浊水域不热带化；
- 极地不更白；
- 沙漠不更亮；
- 陆地无误伤；
- 颜色方向不变得更动画、更制图化。

**产物：** `docs/e1_r4a_regional_preview_[候选版本号].md`，含所有预览图路径与 pass/fail 判断。
