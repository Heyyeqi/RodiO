## 1. 当前阶段背景

RodiO 3D 地球正在推进近海真实感优化。核心问题是 D3 贴图（BMNG 卫星真彩合成）海洋部分在近海陆架区域呈现均质化，缺乏浅水深度梯度感。

本轮在 D4a 保守近海修复验收失败后，正式将路线从「BMNG 贴图微调」转向「真实 bathymetry 数据驱动」。

---

## 2. D4a 结论：BMNG 贴图微调路线关闭

D4a 针对 nearshore_100km / nearshore_170km / shelf / island shelf 等区域叠加了低强度 luminance detail（strength 0.10–0.14），验收结果如下：

| 核心区域 | B_std 变化 | 目标 |
|---|---|---|
| 黄海 | +1.9% | 15–30% |
| 东海 | -1.1% | 15–30% |
| 台湾海峡 | +0.3% | 15–35% |
| 南海北部 | +1.2% | 15–35% |
| 波斯湾 | +3.5% | — |

改善幅度为 0–3%，远低于目标。根本原因：BMNG 海洋像素在合成阶段已丢失深度信息，从 D3 RGB 反推深度属于无据推断，detail_strength 再高也只是在均质蓝上叠加噪声。

**结论：停止 D4b / D5 普通图像微调路线。近海真实感需要外部深度数据驱动。**

| 许可 | 美国联邦政府作品，全球公共领域，无署名要求 |

### 网格参数

| 项目 | 值 |
|---|---|
| 网格尺寸 | 21601 × 10801 |
| 分辨率 | 1 arc-min（~1.85km/px 赤道） |
| 经度范围 | -180.0 → +180.0 |
| 纬度范围 | -90.0 → +90.0 |
| 纬度方向 | north_first（row 0 = 90°N） |
| 深度范围 | -10898m → +8271m |
| 海洋占比 | 66.1% |

### 与 D3 对齐

- D3 贴图为标准等经纬投影（equirectangular），lon -180→+180，lat 90N→90S，8192×4096
- ETOPO1 采用完全相同投影和方向约定
- **无需重投影，无需经度偏移**
- `TEXTURE_LON_OFFSET`（earth3d.js 中 `mesh.rotation.y`）是渲染时旋转，不影响贴图文件本身的存储方向
- ETOPO1 降采样到 8192×4096 可直接与 D3 像素对齐

## 5. 下一步：Bathy-2

- 目标：将 ETOPO1 降采样至 8192×4096，生成 depth-tinted D5a_bathy 候选贴图
- 方案：离线预生成（pre-baked），不做 runtime shader
- depth_norm = `clip(-depth / 200, 0, 1)`（shelf-saturated，200m 以深不再增强）
- 与 D3 soft-blend：浅水像素获得暖调 + 亮度提升，深海保持 D3 不变
- 验收：同等 20 区域 RGB/B_std/saturation 指标 + 视觉对比
- **不修改 earth3d.js**
- **不替换正式 dayTexture**
- **不自动 commit**
