## 0. 审计背景

RW 浏览器目视确认 d5b_design_v3_2_1 可作为 E1-R1 / D5z 输入基线，但指出当前整体仍存在一定
"动画风格 / 游戏地图风格 / 过度增强贴图感"，真实卫星感不足。

本专项审计目标：
1. 量化诊断"动画感"来自哪一层（贴图 / runtime 光照 / BMNG 基线）；
2. 明确哪些问题可以在 E1-R3 贴图层修复，哪些归入 Phase 7；
3. 不修改任何文件。

## 1. 深海地形图化检测

**结论：D5b 未放大深海纹理，但 BMNG 基线本身存在较高的洋底纹理量。**

测量方法：对每个深海采样点截取 160×160px 区域，计算 L* 标准差（std_L）和
Sobel 边缘密度（edge_density，梯度 > 3.0 的像素占比）。

| 区域 | d2 std_L | v3_2_1 std_L | Δ std_L | d2 edge | v3_2_1 edge | Δ edge |
|---|---|---|---|---|---|---|
| Pacific mid-ridge | 8.11 | 7.97 | −0.14 | 0.3709 | 0.3885 | +0.0176 |
| Pacific NW deep | 7.13 | 7.13 | 0.00 | 0.2809 | 0.2841 | +0.0032 |
| Philippine Sea | 5.56 | 5.34 | −0.22 | 0.3396 | 0.3430 | +0.0035 |
| Indian Ocean deep | 9.88 | 9.51 | −0.36 | 0.2086 | 0.2157 | +0.0072 |
| N Atlantic ridge | 3.99 | 3.92 | −0.07 | 0.1646 | 0.1806 | +0.0160 |
| S Atlantic deep | 6.65 | 6.54 | −0.11 | 0.1761 | 0.1864 | +0.0103 |

### 诊断

- D5b v3_2_1 相对于 d2，深海 std_L **全部降低或不变**（范围 −0.36 ~ 0）：
  D5b **未放大**深海地形纹理，略微抑制了一些纹理。
- edge_density 有轻微上升（+0.003 ~ +0.018），幅度极小，属贴图颜色整体调整带来的
  局部对比度微调，**未引入新的洋底边缘**。
- **真正的问题来自 BMNG 基线本身**：深海 std_L 在 4.0–9.9 之间，edge_density 在 0.17–0.37
  之间，说明 BMNG 8K 原始数据在深海已有较明显的 ETOPO1 洋底纹理（中洋脊、海山群、环礁链）。
  这不是 D5b 引入的，是整个 BMNG 路线的基础问题。

### 归属

| 问题 | 归属阶段 |
|---|---|
| D5b 引入深海纹理 | **无**（轻微减少） |
| BMNG 基线深海 std_L 4–10 | **Texture Fidelity Audit（Phase 4）** |

### 2.4 诊断

1. D5b 对所有海域施加了大幅降饱和（全局约 −10.2%），目的是减少 bathymetry map 感。
   效果已达到，但**副作用是全局海洋颜色偏向"灰-暖"色调**，失去了卫星图像中海水本身的
   自然饱和度与色彩层次。

2. B/R 比例从 2.60 降至 2.07，深蓝色海洋特征大幅减弱。真实卫星图像中深海 B/R 通常在
   2.2–3.0 之间，当前 2.07 偏低。

3. 浑浊水域降饱和幅度最大（−9 ~ −18%），这符合 D5b 设计意图（防热带化），但降幅可能
   过大，导致颜色看起来像"漂白的地图颜色"，而非真实浑浊海水。

4. 色相多样性（H std 38.5°→38.2°）基本保留，说明不同海域的颜色方向差异还在，只是
   全局整体偏灰暗了。

5. **与 Natural Earth 制图风格的距离**：Natural Earth 海洋 S% ≈ 50%，v3_2_1 全局海洋
   S% = 52.2%，两者差距极小（仅 2.2%），说明 D5b 的降饱和使贴图颜色向制图风格靠拢。

### 诊断

- 15 个陆地采样点中，13 个 |ΔS| < 2%，land mask 保护有效。
- 2 个 ⚠ 点（SE Asia forest −12.3%，European farmland −4.4%）与 ocean-land 边界混采有关

- **主要陆地卡通化风险来自 noon runtime**：sun=1.25 强光照将陆地整体提亮，使颜色偏浅
  偏干净，视觉上接近制图色，这是 runtime 层问题，不在贴图层处理。

## 4. 正午大气 / 光照滤镜感诊断（只读）

**结论：noon 模式的 atmosphere + sun 配置是"过度干净/亮白感"的主要 runtime 来源，
归属为光照层问题，不修改 earth3d.js。**

### 4.1 当前 noon 配置（earth3d.js，只读）

```
mapColor:    0xffffff      → 不对贴图施加颜色偏移（中性）
atmosphere:  #b0d9ed       → 淡天蓝（R:176, G:217, B:237），opacity: 0.14
sun:         1.25          → 强日照
ambient:     0.09
specular:    0x091018，shininess: 1.12
```

### 4.2 atmosphere 覆盖效果模拟

公式：result = texture × (1 − 0.14) + atm × 0.14

| 区域 | 贴图原色 | 叠加大气后 | ΔR | ΔG | ΔB | 主要效果 |
|---|---|---|---|---|---|---|
| 深海 | (31, 48, 74) | (51, 71, 96) | +20 | +23 | +22 | 大幅提亮，深蓝感减弱 |
| 热带浅海 | (84, 129, 143) | (96, 141, 156) | +12 | +12 | +13 | 均匀提亮 |
| 南极冰盖 | (223, 225, 227) | (216, 223, 228) | −7 | −2 | +1 | 轻微冷移 |
| 撒哈拉 | (196, 171, 132) | (193, 177, 146) | −3 | +6 | +14 | B +14，沙漠偏冷白 |
| 雨林（估算） | (60, 95, 60) | (76, 112, 84) | +16 | +17 | +24 | 整体提亮，绿色略冷 |

### 4.3 归因结论

1. **atmosphere #b0d9ed + opacity 0.14 对深色区域（深海、森林）贡献 +18~23 的均匀提亮**，
   是"动画感/过度干净"的主要 runtime 贡献者——深海在贴图中是暗蓝 (31,48,74)，
   叠加大气后变成 (51,71,96)，视觉上海洋整体偏亮偏浅。

2. **sun=1.25 强光照**对正对太阳的浅色表面（沙漠、浅海）产生额外约 +20% 亮度提升，
   叠加 atmosphere 后极易在沙漠和冰雪区域造成过曝。

3. **撒哈拉 B 通道 +14** 是沙漠"过度干净/偏冷白"感的来源——沙漠本身是暖黄棕色，
   atmosphere 冷移后变成偏白灰。

4. **specular shininess=1.12** 对水面产生反光高光，可能贡献局部过曝感。

5. 以上四点**全部归属 Phase 7（光照/atmosphere 专项）**，不在贴图层处理，不修改 earth3d.js。

## 5. 浅深对比度检测（水深图化风险）

测量方法：对浅海/深海配对区域分别采样，计算 L* 差值（ΔL*）。
ΔL* > 18 → 浅深对比过强，有地图化风险。

| 浅海区 → 深海区 | d2 ΔL* | v3_2_1 ΔL* | 变化 | 风险 |
|---|---|---|---|---|
| Bahamas → Bahamas deep | 2.2 | 3.0 | +0.7 | OK |
| Persian Gulf → Arabian Sea | 25.1 | 28.2 | +3.1 | **HIGH-map** |
| S China shallow → S China deep | 1.9 | 4.9 | +3.0 | OK |
| Yellow Sea → Pacific NW | 28.2 | 30.9 | +2.7 | **HIGH-map** |
| Caribbean shallow → Caribbean | −7.4 | −8.6 | −1.2 | OK |

注：Persian Gulf 和 Yellow Sea 的 HIGH-map 标记，主要来自这两个海域浑浊处理后
（颜色变暖/变亮）与周边深海的亮度落差拉大。这与浅海层次增强无关，而是浑浊水域
的暖移与深海的暗色调形成强对比。E1-R3 收窄浑浊降饱和幅度后此指标应改善。

## 6. 综合结论

### 6.1 动画感风险等级汇总

| 来源 | 风险等级 | 主因 |
|---|---|---|
| 海洋降饱和过多（贴图层） | **HIGH** | D5b 全局 S% 降 10.2%，海洋偏向制图灰色而非真实卫星饱和蓝；B/R 降至 2.07（真实应 2.2–3.0） |
| 热带浅海颜色方向偏差（贴图层） | **MEDIUM** | 颜色向暖黄移动（R↑G↑B↓）而非真实热带青绿（H: 185–205°） |
| 深海 BMNG 洋底纹理（基线层） | **MEDIUM** | BMNG 本身深海 std_L 4–10，中洋脊/海山可见，非 D5b 引入 |
| noon 大气提亮滤镜（runtime 层） | **HIGH** | atmosphere #b0d9ed opacity 0.14 + sun 1.25，整体过亮过冷白 |
| 陆地卡通化（贴图层） | **LOW** | D5b 保护有效；noon 光照叠加后轻微可见，但不是主问题 |
| 全局颜色均质性 | **MEDIUM** | H std 保留但 S std 下降，海洋色调分化减弱，接近 Natural Earth 制图 S% |

### 6.2 分层归因与修复路径

**应由贴图层修复（E1-R3 候选生成时实施）：**

1. **海洋全局降饱和过量**
   - 当前：全球海洋 S% = 52.2%，B/R = 2.07
   - 目标：全球海洋 S% 回升至 55–58%，B/R 回升至 2.2–2.5
   - 方向：在全局或分区适当回升饱和度，保持 D5b 的浅深层次，但不过度压灰

2. **热带浅海颜色方向修正**
   - 当前：浅海增强方向偏暖（R↑G↑B↓）
   - 目标：热带浅水目标色 H 应在 185–205°（蓝绿/青蓝），而非当前偏暖的 190–208°
   - 典型现象：Bahamas 从 (68,119,153) 变成 (84,129,143)，颜色偏暖而非偏青绿

3. **浑浊水域降饱和幅度适当收窄**
   - 当前：Yellow Sea −18%，Persian Gulf −9%，Yangtze −10%
   - 目标：浑浊水域 ΔS 控制在 −5 ~ −8%（保留浑浊感，但不漂白）
   - 理由：过度降饱和使浑浊水域颜色像"处理过的地图灰色"，而非真实浑浊海水的灰绿/黄绿

**应由 noon runtime 修复（E1-R2 确认归因后进入 Phase 7）：**

1. atmosphere opacity 0.14 偏大，对深色区域提亮过多（+20 RGB）
   → 考虑降至 0.10–0.11
2. sun=1.25 在正午过强，可能需要降至 1.0–1.1
3. 撒哈拉/冰雪区域 B 通道冷移（+14）
4. specular shininess=1.12 可能贡献局部水面过曝感

**应由 Texture Fidelity Audit（Phase 4）处理：**

1. BMNG 深海 std_L 4–10（洋底纹理）
   → 评估是否可通过 JPEG 压缩质量提升或纹理过滤参数缓解，不修改贴图颜色

### 6.3 最终结论

**d5b_design_v3_2_1 可作为 E1-R1 / D5z 输入基线。**

d5b_design_v3_2_1 通过了 Phase 3 贴图层保护性验收（深海/极地/陆地保护有效，无热带化）。
E1-R1A 发现的"动画感"问题来自三个层次，各有明确的处理路径：

| 层次 | 问题 | 处理 |
|---|---|---|
| 贴图层 | 海洋降饱和过量、热带浅海色相偏暖、浑浊水域降幅过大 | **E1-R3 候选生成时必须修正** |
| Runtime 光照层 | noon atmosphere 提亮 +20 RGB、sun=1.25 过强、沙漠冷移 | **E1-R2 归因 → Phase 7 修复** |
| BMNG 基线层 | 深海洋底纹理 std_L 4–10 | **Phase 4 Texture Fidelity Audit** |

v3_2_1 作为输入基线：**✅ 确认有效。**
E1-R3 候选生成时，必须针对以下三项进行修正：
1. 全局海洋饱和度回升至 55–58%（B/R 回升至 2.2–2.5）；
2. 热带浅海目标色相方向调整至 H: 185–205°（青蓝方向）；
3. 浑浊水域降饱和幅度收窄至 ΔS −5 ~ −8%。

noon atmosphere / sun / specular 问题**归入 E1-R2 + Phase 7**，不在贴图层处理。

## 附录：测量环境与数据说明

- **测量工具**：Python 3 / PIL (Pillow) / NumPy
- **所有测量均在 JPG 贴图文件上直接进行**，不经过 Three.js 渲染、光照或 atmosphere 叠加
- **L\* 转换**：sRGB → linear RGB（gamma 2.2）→ Y → CIE L\*
- **H/S/V 转换**：RGB → 标准 HSV，H 范围 0–360°，S/V 范围 0–100%
- **std_L**：样本区域内所有像素 L\* 值的标准差（纹理量指标）
- **edge_density**：Sobel 梯度幅度 > 3.0 的像素占样本区域总像素的比例
- **全局海洋统计**：基于下采样至 2048×1024 的全图，使用 `R<150 AND B>R AND B>G` 的简单海洋像素掩码
- **atmosphere 模拟**：简化线性 overlay 公式，不考虑 Three.js 渲染管线细节，
  仅用于定性归因，不作为精确修复参数
