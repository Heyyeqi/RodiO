## 0. D5z 的定位

D5z 是 **E1 Day Earth Master 的子专项**，不是独立路线。

D5z 处理 E1 中以下两个问题域中**属于浅海贴图层面可处理的部分**：
- 问题域 5A：海洋层次不足（A 类采样点）
- 问题域 5B：太平洋岛屿领土感不足（A 类岛礁）

D5z **不处理**（明文禁区）：
```
× 沙漠过曝            → E1-R2 归因 + Phase 7
× 极地过曝            → Phase 7（E1-R2 归因后确认）
× 冰川纹理丢失        → Phase 7 或 E1-R3（视 E1-R2 归因结论）
× 陆地地貌糊化        → E1-R3 全局调整
× noon runtime 曝光   → E1-R2 审计
× atmosphere / 辉光   → E5
× 云层                → E4
× 夜晚海水            → E2
× 大堡礁精细化        → Phase 8（暂缓）
× 天气 / 七曜         → 远期冻结
```

---

## 1. D5z 授权范围

| 问题 | 处理方向 |
|---|---|
| 热带清澈浅海层次不足 | 增强近岸浅水/礁盘/沙洲的青绿-蓝色差 |
| 热带岛礁领土感弱 | 轻微扩大 island halo，增加浅水可见度 |
| 浅深过渡过硬 | 增强 feather / blur，让边界更柔和 |
| 浑浊水域防误操作 | 钳制 saturation，防止 D5b 后叠加新增错误增强 |

## 3. Google Maps / Google Earth 截图使用约束

D5z 中 Google Maps 截图的使用约束继承自父文档，并额外强调：

```
A 类采样点（长滩岛、马尔代夫等）的 Google Maps 截图（REF-01/02/03 等）：
  ✓ 允许：作为人工视觉参考，判断增强方向是否符合审美预期
  × 禁止：提取截图像素颜色作为 D5z 生成脚本的输入参数
  × 禁止：将截图中的颜色数值写入 d5b_processor_v3/config.py 任何参数
  × 禁止：截图进入 production / candidates / source/bmng_staging 目录

增强方向的量化依据只能来自：
  1. Sentinel-2 L2A 样本（测量值）
  2. NASA BMNG 对应区域测量值
  3. 父文档 E1-R0 阶段定义的指标目标范围

若 Sentinel-2 与 Google 视觉判断方向一致，Google 可作为"定性确认"，
但最终生成参数必须基于 S-2 测量值，不基于 Google 截图颜色。
```

**风险隔离声明（继承父文档，在 D5z 层再次确认）：**
```
若本项目未来公开、开源或商业化，D5z reference 目录中的
Google Maps 截图必须在公开前重新审查保留方式，
默认处理方式是在公开前删除全部截图。
```

## 5. 三方冲突预案

| 冲突点 | 风险描述 | 预案 |
|---|---|---|
| A3 大堡礁 | ETOPO1 精度不足，8K 全局图无法实现 S-2/Google 所示礁盘细节 | 目标定为"不比 D5b 更差"，精细化推迟到 Phase 8 |
| B1 波斯湾 | 季节和年际浑浊度变化大 | 以 NASA NEO 叶绿素年均图确认高浑浊区边界；不以单次 S-2 样本为准 |
| A1 长滩岛 | Google 截图比 S-2 更饱和 | 以 S-2 L2A 测量值为参数上限；Google 仅确认增强方向是否合理 |

## 6. 执行顺序约束

D5z 候选生成必须满足以下所有前置条件：

```
前置条件 1：D5b v3.2.1 上球视觉验收通过（Phase 3），
            RW 确认其为 D5z 的输入基线。

            注：是否将 d5b_design_v3_2_1 设为 DAY_TEXTURE_VARIANT 默认值，
            属于 E1-R6 production decision，不是 D5z 候选研究的硬前置。
            D5z 研究可以在 D5b 被确认为输入基线后启动，
            无需等待 earth3d.js 默认值更改。

前置条件 2：E1-R0 基线文件（父文档 + 本文件）经 RW 确认。

前置条件 3：E1-R1 指标测量完成，50 点均有基线值，
            所有"暂定"阈值经 RW 重新确认。

前置条件 4：E1-R2 归因审计完成，确认沙漠/极地问题根因。
            （确保 D5z 不因误操作碰触非贴图问题区域）

前置条件 5：参考图 REF-01/02/03 已存档至 source/reference/google_maps/，
            并标注"visual reference only"。

前置条件 6：至少 A1、A2、A4 三点的 Sentinel-2 样本已采集并核实 Tile 编号。
```

## 8. D5z 候选后的 Regional Visual Preview 要求

任何 D5z 候选生成后，必须同步生成区域预览，不得只输出全局贴图和指标。
**没有 Regional Visual Preview，不得进入 E1-R5，也不得进入 production decision。**

### 8.1 必须输出

**① 平面区域对比图**

三列并排，同尺寸、同裁剪范围：
- bmng_d2
- d5b_design_v3_2_1
- d5z_candidate

**② 差异图**

- abs diff：d5z_candidate vs d5b_design_v3_2_1
- saturation diff
- Lab L* diff
- RGB channel diff summary

**③ 重点区域放大图**

```
必须改善区：长滩岛、马尔代夫、大堡礁、巴哈马、红海、帕劳、夏威夷
必须保护区：波斯湾、黄海、东海、日本海、亚马逊河口
不得误伤区：太平洋深海、南极、格陵兰、撒哈拉、澳洲内陆
```

**④ 固定视角上球截图**

- 固定 noon 模式（`window.earth3d.setTimeOfDay("noon")`）
- 固定相机视角
- 同一区域分别截图 d5b_design_v3_2_1 与 d5z_candidate
- 每张截图写明 URL 参数、定位坐标、截图路径

### 8.2 通过条件

| 类别 | 条件 |
|---|---|
| A 类目标区 | 浅海层次改善，色相向 H°=195–210° 方向修正 |
| B 类浑浊区 | 没有热带化（S% 不超出保护阈值） |
| D 类深海区 | 没有发灰、发脏或新增纹理（std_L 不超出 BMNG 基线水平） |
| F 类极地区 | 没有更白（L* 不升高，p95_L 不升高） |
| E 类沙漠区 | 没有更亮（L* 不升高，p95_L 不升高） |
| 所有陆地区 | 无可见误伤（ΔS ≤ 2%，ΔL* ≤ 2） |
| RW 主观判断 | 配色方向可接受，不更动画、不更制图化 |

### 8.3 输出路径

```
docs/d5z_r4a_regional_preview_v[N].md      ← 预览报告
pwa/assets/source/bathy/preview/d5z_v[N]/  ← 所有预览图文件
```
