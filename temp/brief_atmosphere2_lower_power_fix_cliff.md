## 背景(根因已确认)

审计确认：`atmosphere2`当前`power=3.0左右`这个Fresnel衰减指数太陡——配合`earthGroup`的Y轴偏移导致的上下视线夹角差异，下方(3-7点方向)的实际渲染亮度值远低于上方，在深色背景下肉眼看起来就是"完全消失"，但不是真的被裁剪掉(极限值测试opacity=1.0/power=1.0时3-7点方向确实会显现)。

## 要做的事

调整`FAR_VIEW_ATMOSPHERE`常量里的`power`(以及可能需要联动调整`powerOuter`)，让Fresnel曲线更平缓，缩小上下亮度差距。这次给一个起点方向，需要你实际视觉测试确认：

```js
const FAR_VIEW_ATMOSPHERE = { opacity: 0.34, sunInfluence: 0.08, power: 1.6, powerOuter: 1.3, strengthOuter: 0.22 }
```

（`power`从原来的~3.0降到`1.6`左右，`powerOuter`同步降到`1.3`左右——这两个数值只是估算起点，不是精确值，**请你先用之前审计时的同一个方法（`getAtmosphere2Mat()`直接改uniform）在farOrbit构图下实时试几组`power`值，比如从`1.2`到`2.5`之间找一个既能让3-7点方向清晰可见、又不会让整个球体看起来像"整体蒙了一层白雾"(power太低会让fresnel在球体中心区域也有明显强度，不再像贴着轮廓的"rim"效果，而像整体蒙层)的平衡点**。找到满意的数值后再写回`FAR_VIEW_ATMOSPHERE`常量。

`opacity`如果`power`降低后发现顶部反而显得太亮/过曝，可以适度下调；如果找到好的`power`后顶部/底部都偏暗，可以适度提高`opacity`——这两个参数需要配合看效果，不是只调一个。

## 验证方式(这次请按12/3/6/9点四个方位仔细看，不要只看整体截图)

1. `farOrbit`构图下，12点、3点、6点、9点四个方位辉光都清晰可见，肉眼看不出"某个角度突然完全没有"这种断崖感
2. 整体观感依然是"贴着球体轮廓的柔和辉光环"，不是"整个球体蒙了一层均匀雾气"(如果power降得过低会变成这样，需要往回调)
3. 顶部(朝阳侧)不应该因为这次调整变得过曝刺眼
4. 近景构图(homeGlobe等，如果之前已经应用了atmosphere2)、夜间主题不受影响
5. 控制台无新增报错
